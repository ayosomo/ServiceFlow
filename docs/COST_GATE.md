AWS plan terms distinguish free and paid account plans; inspect the actual Billing console rather than assuming the owner is a new customer. Verify every relevant allowance and region, including HTTP API, provisioned DynamoDB transactions, CloudWatch and the SAM S3 bucket. A Lambda allowance alone does not cover the complete architecture. [AWS account plans](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/free-tier-plans.html), [Lambda pricing](https://aws.amazon.com/lambda/pricing/), [DynamoDB pricing](https://aws.amazon.com/dynamodb/pricing/), [API Gateway pricing](https://aws.amazon.com/api-gateway/pricing/).

Azure consumption grants do not establish zero cost for Blob/Queue host storage. Avoid Always Ready/Premium. The supplied template uses Windows Consumption and a polling Blob trigger, so it does not imply compatibility with Flex Consumption's event-only trigger. Managed identity host permissions and code deployment still need live validation. [Functions pricing](https://azure.microsoft.com/en-gb/pricing/details/functions/), [Storage pricing](https://azure.microsoft.com/en-gb/pricing/details/storage/blobs/), [Blob trigger](https://learn.microsoft.com/en-us/azure/azure-functions/functions-bindings-storage-blob-trigger), [Azure account](https://azure.microsoft.com/en-gb/pricing/purchase-options/azure-account/).

Cloud Run compute allowances do not cover every related cost; image storage/build, logging, egress, Firestore usage and region choice must be reviewed together. Firestore's documented free quota is for one eligible database per project; exclude PITR/backups/TTL. Use min instances 0, max 1, request CPU billing. [Cloud Run pricing](https://cloud.google.com/run/pricing), [Firestore pricing](https://cloud.google.com/firestore/pricing), [Artifact Registry pricing](https://cloud.google.com/artifact-registry/pricing), [Budgets](https://docs.cloud.google.com/billing/docs/how-to/budgets).

Before requesting approval: authenticate interactively outside chat; inspect actual account plan/credits/expiry, allowed regions/services, current usage and policies; complete the usage estimate against those terms; define retention/teardown time and residual bill checks; provide a concrete resource list. Never ask for keys in chat. The current gate is incomplete and cannot support a chargeable deployment approval request yet.
