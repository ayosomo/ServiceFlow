# KPI catalogue

asOf defaults to **2026-10-23T00:00:00.000Z**, never the host clock. API supports another explicit UTC timestamp/date. Empty ratio denominators yield null. Late but accurate data is not a quality failure. Pending approval is not a quality failure.

| KPI                | Numerator                                                        | Denominator / exclusion                                                                                | Boundary / interpretation                                                                                                   |
| ------------------ | ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| Quality pass rate  | Schema-valid unique CRM rows with no critical finding on that ID | All raw rows with valid identifiable ID; missing/invalid IDs disclosed separately                      | 41/47; one unidentifiable row. REVIEW does not fail quality. Both duplicate occurrences fail.                               |
| Readiness rate     | Assessable active records without pending approval               | All assessable SUBMITTED/APPROVED/IN_PROGRESS records; excludes other states and critical invalid rows | Pending = approvalRequired and no approverId. It is operationally blocked.                                                  |
| Overdue count      | Assessable active targetAt < asOf                                | Assessable active records; exclusions shown                                                            | Exact equality is not overdue. Not a quality score.                                                                         |
| On-time completion | Assessable DONE with completion <= target                        | Assessable DONE with valid dates; other records excluded                                               | Equality counts on time; completion before submission is invalid.                                                           |
| Exception backlog  | All OPEN findings                                                | Finding count, not request count                                                                       | Split CRITICAL/REVIEW; API allows owner/source/row inspection. No resolution endpoint, so all initial findings remain OPEN. |

API returns definitions and numerator/denominator/exclusions for ratios, snapshot on every KPI response and a source hash for provenance. Request drill-down explicitly returns FAIL/UNASSESSABLE for critical source records; valid records expose distinct quality/readiness/performance statuses. Corrective actions use actual rule IDs and record values.

The checked-in generated [metric snapshot](../packages/fixtures/data/kpis.json) contains exact seed counts. [SQL reference](../db/queries/reference.sql) independently implements eligible/active/ready/overdue/done/on-time aggregates using joins, ROW_NUMBER and FILTER. Its eligibility list is the shared validated boundary; the aggregation is independent, not a second call to the TypeScript KPI function.
